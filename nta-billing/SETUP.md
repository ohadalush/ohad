# התקנה (פעם אחת, כ-10 דקות)

## 1. התקנות
1. **Python 3.11 ומעלה:** מורידים מ-[python.org/downloads](https://www.python.org/downloads/). בהתקנה מסמנים ✅ **Add python.exe to PATH**.
2. **LibreOffice (רשות, רק ל-PDF):** מורידים מ-[libreoffice.org/download](https://www.libreoffice.org/download/download/). חישוב הנוסחאות נעשה בקוד עצמו ולא צריך אותו. בלי LibreOffice הכול עובד, רק ה-PDF של פירוט הכמויות לא נוצר (מופיעה אזהרה).
3. **Claude Code:** אם עוד לא מותקן, ההוראות ב-[docs.claude.com/en/docs/claude-code](https://docs.claude.com/en/docs/claude-code/overview).

## 2. הכנת התיקייה
1. מחלצים את ה-ZIP למקום קבוע, למשל `C:\נתע\nta-billing` או תיקייה בגוגל דרייב.
2. פותחים טרמינל בתוך התיקייה ומריצים:
   ```
   pip install -r requirements.txt
   python cli.py list 7
   ```
   אם מופיעה טבלה עם הזמנה 1549 (כהן אלדן), ההתקנה עובדת.

**אם LibreOffice מותקן אבל לא נמצא:** מגדירים משתנה סביבה `NTA_SOFFICE` עם הנתיב המלא, בדרך כלל
`C:\Program Files\LibreOffice\program\soffice.exe`.

**מנוע החישוב:** ברירת המחדל היא המנוע המובנה (`engine/xlcalc.py`). כדי לחשב עם LibreOffice כמו פעם, מגדירים `NTA_RECALC=libreoffice`. אם נוסחה משתמשת בפונקציה שהמנוע המובנה לא מכיר, הוא עובר ל-LibreOffice לבד (אם מותקן), או נכשל עם הודעה ברורה. הוא אף פעם לא מחזיר מספר שגוי בשקט.

## 3. עבודה יומיומית
פותחים את Claude Code בתיקייה (`claude`). הוא קורא אוטומטית את `CLAUDE.md` עם כל הכללים.

| מה כותבים ל-Claude | מה קורה |
|---|---|
| "תוסיף לחשבון 7" + גוררים קובץ סיכום (או שמים ב-`inbox`) | `add` |
| "שאילתא על הקובץ הזה" | `query` |
| "בהזמנה 1549 תוסיף 3 מ"ר רשת" | `set` + כמה זה הוסיף |
| "תפיק את חשבון 7" | `build`: חשבון מאוחד, רשימת הזמנות, פורמט נתע ובדיקות |

אפשר גם להריץ את הפקודות בעצמך בלי Claude, בלי טוקנים בכלל. אחרי `add` שמגיע לשאלות עם תשובות, מוסיפים `--set ... --force`.

**כדי לחסוך בטוקנים:**
- פותחים שיחה חדשה (או `/clear`) לכל חשבון, או כשהשיחה מתארכת.
- הכללים לא הולכים לאיבוד בשיחה חדשה, כי הם כתובים ב-`CLAUDE.md`.

**הערות:**
- סוגרים ב-Excel קובץ לפני שמבקשים לבנות אותו מחדש. קובץ פתוח נעול לכתיבה.
- מגבים את התיקייה (דרייב או git). כל המצב שמור בה: `accounts/*.json` והקוד.
